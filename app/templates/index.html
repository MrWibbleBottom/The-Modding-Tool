          Help & Feature Guide — How Everything Works
          Reference
        

        

          A complete breakdown of every tab, button, and background process in the application.
        

      


      

        
1. Game Manager

        

          

            
Game scan

            

              Discovers installed PC games across Steam, Epic Games, GOG Galaxy, Xbox / PC Game Pass, Ubisoft Connect, EA Games, or a custom folder path. Searches up to 3 subdirectory levels for game executables (so games like Days Gone or Elden Ring in nested folders are detected), tracks live progress with the scan progress bar, and automatically runs a Game info metadata pass.
            

          

          

            
Game info

            

              Inspects each managed game folder on disk to populate its engine, scripting backend, Unity/metadata version, anti-cheat status, and recommended MCP modding stack.
            

          

          

            
Browse, Add/Edit Game & Icons

            

              Lets you pick any local folder or manually configure a game profile. Game icons are automatically extracted from each game's primary executable and cached locally for fast loading.
            

          

        

      


      

        
2. Active Game & Fingerprint

        

          

            
What does Fingerprint do and how does it work?

            

              Fingerprint inspects the target game directory (POST /api/fingerprint) and computes SHA-256 hashes of key binaries (such as GameAssembly.dll, UnityPlayer.dll, or main executables). It detects the engine (Unity IL2CPP/Mono, Unreal 4/5, Creation, Godot, RE Engine, FromSoftware, Data-Driven, or Native C++), Unity build & IL2CPP metadata version, anti-cheat binaries, and whether Doorstop/BepInEx/MCP Bridge/Interop DLLs are present. Fingerprint & Rescan combines this check with a full Game Info refresh.
            

          

          

            
Provision & Clean Restore

            

              Verifies the BepInEx 6 IL2CPP archive SHA-256, backs up any colliding files into %LOCALAPPDATA%\ModToolPoC, extracts BepInEx and BepInExMCP.IL2CPP.dll, and writes a manifest so Clean Restore can revert every deployed file cleanly.
            

          

          

            
Steam Artwork, Unreal Traffic Light & Live MCP

            

              Pulls local Steam librarycache hero banners and thumbnails when available. For Unreal Engine games, imports GameUserSettings.ini / Engine.ini and scores settings against your PC Specs (Green / Amber / Red). For running Unity IL2CPP games, connects over persistent stdio to bepinex-mcp for live object/component inspection and editing.
            

          

        

      


      

        
3. Build a Mod

        

          

            
How Mod Building Works

            

              Import live MCP edits or add custom rules, then click Build Compatible Mod:
              
• Unity IL2CPP: Generates a BepInEx 6 C# BasePlugin (Plugin.cs) with Config.Bind entries and scene-load hooks, compiles it as a net6.0 .dll directly against the target game's BepInEx\core\*.dll and BepInEx\interop\*.dll via dotnet build, and packages it with INSTALL_INSTRUCTIONS.txt into a .zip.
              
• Unreal Engine 4/5: Generates an RE-UE4SS main.lua script + GameUserSettings_Override.ini + INSTALL_INSTRUCTIONS.txt package.
              
• Install Built Mod to Game deploys the compiled package directly into the game folder.
            

          

        

      


      

        
4. PC Specs & Audit Log

        

          

            
PC Specs

            

              Scrapes CPU, GPU (VRAM, driver, temperature), RAM, drives, OS, and display resolution/refresh rate, caches results for instant loading, and maps your PC to an Unreal hardware reference tier.
            

          

          

            
Audit Log

            

              Records every scan, fingerprint, provision, restore, mod build, backup, and setting change with timestamps, status, SHA-256 digests, and expandable detail summaries in %LOCALAPPDATA%\ModToolPoC\audit.jsonl.
            

          

        

      


      

        
5. App Management

        

          

            
Portable App Export

            

              Packages the app, MCP bridge, pre-built plugins, branding folders, and Launch_ModToolPoC.bat into a downloadable ModToolPoC-Win64.zip for other Windows 10/11 PCs.
            

          

          

            
Tool Upgrades & Checksums

            

              Upgrades or rebuilds BepInEx 6, BepInExMCP.IL2CPP, RE-UE4SS, and MelonLoader with HTTPS-only enforcement, SHA-256 checksum verification, and automatic pre-upgrade backups.
            

          

          

            
App Editing & WIP Flags

            

              Rename the app/tabs, upload a responsive banner (branding/banners) and favicon (branding/favicons), show/hide elements, or flag any section as In Progress (WIP).
            

          

          

            
Save & Restore Versions

            

              Creates incremental and baseline project backups with expandable change summaries (SUMMARY.md) so you can restore the project to any previous version.
